造号师是一款基于浏览器自动化技术的**账号批量注册辅助工具**，旨在帮助开发者和研究人员了解浏览器自动化、指纹浏览器等技术原理。

---

## 📥 下载安装

### 方式一：从 GitHub Releases 下载（推荐）

前往 [Releases 页面](https://github.com/lannickytang-lang/zaohaoshi/releases) 下载最新版本的安装包：

1. 点击最新版本下的 `.exe` 安装文件下载
2. 双击运行安装程序，按提示完成安装
3. 安装完成后桌面会生成 **「ZaoHaoShi」** 快捷方式，双击即可启动

> 💡 软件支持**自动更新**，启动时会自动检测并安装新版本，无需手动重复下载。

### 系统要求

- **操作系统**：Windows 10 / 11（64 位）
- **内存**：建议 4GB 以上
- **磁盘空间**：至少 500MB（含内置浏览器）
- **网络**：需要稳定的互联网连接

## ✨ 功能特性

### 核心功能

- **批量账号注册** — 支持创建注册任务，自动化完成账号注册流程
- **多平台支持** — 支持即梦国际版 (Dreamina)、小云雀国际版 (Pippit) 等平台
- **多邮箱类型** — 支持 MinMail、Outlook、1SecMail、GuerrillaMail 等多种临时/持久邮箱
- **并发执行** — 支持多线程并发注册，可自定义并发数
- **智能验证码处理** — 自动轮询邮箱获取验证码并完成填写

### 账号管理

- **账号列表** — 查看所有已注册账号，支持筛选和搜索
- **一键登录** — 启动浏览器并自动登录已注册账号
- **批量登录** — 同时登录多个账号
- **独立窗口** — 为指定账号打开独立浏览器窗口
- **手动添加/导入** — 支持手动添加账号或批量导入

### 邮箱管理

- **邮箱池** — 管理持久型邮箱（如 Outlook），支持批量导入
- **卡密提取** — 支持从卡密平台 URL 自动提取邮箱信息
- **使用记录** — 追踪每个邮箱的使用状态，连续失败自动禁用

### 任务调度

- **任务创建** — 灵活配置平台、邮箱类型、数量、并发数、密码策略
- **实时监控** — 通过 SSE 推送实时查看注册进度和子任务状态
- **任务控制** — 支持发布、暂停、重启任务

### 浏览器管理

- **内置指纹浏览器** — 自动检测和安装，无需额外配置
- **会话管理** — 自动管理浏览器会话生命周期
- **可视模式** — 可选择显示/隐藏浏览器窗口，方便调试
